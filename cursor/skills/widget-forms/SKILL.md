# Choices and previews in Cursor

Use normal chat for missing details and short numbered choices. Keep returned preset/voice IDs internal. Offer references or a playable sample only when the tool returned one and Cursor can actually show it. Do not promise a form, player or audio control just because a shared workflow describes one.

A project is reviewed in the ChatCut editor. Use the Cursor handoff rules in `chatcut-plugin-basics`: send the named clean editor link, or open a server-issued handoff privately in Cursor's Browser when available. Never use `show_preview` or the inline project card. A visible sign-in or loading screen is not an open editor. For finished media, verify and deliver the requested export itself.
