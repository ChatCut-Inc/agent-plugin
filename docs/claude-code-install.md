# Install ChatCut with Claude Code

ChatCut Desktop is the default. Read the full official setup guide with:

```sh
curl -fsSL https://chatcut.io/desktop
```

On Windows use `curl.exe`. Follow the guide to install, sign in and verify the local `chatcut_desktop` tools. Desktop supplies its current editing Skills, including `video-gen` for reference-video recreation via `submit_video_remake`. No Node.js or npm is required for installation. Run setup on a supported macOS or Windows computer with a graphical desktop; Linux or a remote agent without access to that computer cannot install it there. Continue in a local agent on the supported computer.

For an existing Web project or an explicit hosted-only request, use [the Web plugin guide](https://chatcut.io/web-plugin/claude), also retained in [claude-code-web-install.md](claude-code-web-install.md). Keep existing projects and media. Desktop may disable or replace the same agent’s conflicting hosted connection during setup.
