# Target-script method sources

The existing target-script branch uses original ChatCut guidance informed by these MIT-licensed sources, inspected at fixed revisions. No third-party code or helper is bundled.

- **browser-use/video-use:** [skill](https://github.com/browser-use/video-use/blob/43cfc566833548093455c9d4a46bd69913b7e552/SKILL.md) and [transcript packer](https://github.com/browser-use/video-use/blob/43cfc566833548093455c9d4a46bd69913b7e552/helpers/pack_transcripts.py). Useful ideas: retain source word timing, read compact source-addressed text, reuse transcripts, and inspect visuals at editing decisions. ChatCut already provides canonical transcripts and Script/library views; adding the packer's separate cache or format would duplicate that state.
- **arnans/video-pipeline-skills:** [scripted-narration skill](https://github.com/arnans/video-pipeline-skills/blob/4394273a3152b68dbc584f8fa28dde039ac72cfc/skills/video-scripted-narration/SKILL.md) and [alignment helper](https://github.com/arnans/video-pipeline-skills/blob/4394273a3152b68dbc584f8fa28dde039ac72cfc/skills/video-scripted-narration/scripts/align_narration.py). Useful distinction: a passage match is separate from its actual speech span, and weak or missing passages remain visible. Its sequential segmented-take assumptions do not handle arbitrary reordered footage and retakes; its normalizer retains ASCII and Thai rather than supporting languages generally. Interpolated times cannot establish source cut boundaries.

Adaptation uses native source evidence, semantic take selection, explicit gaps, and existing Script validation. It adds no alignment algorithm, hardcoded confidence thresholds, mandatory review artifact, human approval gate, external ASR/NLE XML pipeline, or runtime dependency.
