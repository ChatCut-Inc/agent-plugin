# ChatCut Captions Guide

## Workflow

1. Confirm the source video or audio is already in the target project; import it first if necessary.
2. For “转写”, create or read the transcript and check that it is ready before styling captions.
3. For “加字幕”, preserve the transcript text and use the caption editing flow for timing, language, layout, and style.
4. For “去停顿/去口癖”, make a timeline edit based on transcript ranges; do not alter caption text as a substitute for cutting media.
5. Read the caption state and a representative timeline frame after changes.

Ask only for a missing language, caption style, or output format when the request cannot be completed safely without it. Keep captions editable unless the user asks for a subtitle file export.
