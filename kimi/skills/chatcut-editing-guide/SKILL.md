# ChatCut Editing Guide

Use ChatCut as an editable timeline, not as a one-shot render service.

## Standard workflow

1. If the user names an existing project, target that project. Otherwise create a project only when the user asks to start a new edit.
2. Before changing timeline content, read the current project state so manually made edits are not overwritten.
3. Open the project in the Kimi Work in-app browser before the first change so the user can watch the edit.
4. Make only the requested changes. Do not silently add music, captions, transitions, or effects.
5. Read the project or render a representative frame after the change and report the visible result.

## Common requests

- “剪掉开头/结尾”：inspect the relevant video item, then trim its range.
- “删除停顿/口头禅”：use transcription and speech-cleanup guidance before removing ranges.
- “加字幕”：load the captions guide.
- “导出”：load the export guide and ask for format or quality only when needed.

Keep the final result editable in ChatCut. Export only when the user explicitly asks for a file.
