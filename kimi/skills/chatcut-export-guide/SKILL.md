# ChatCut Export Guide

Export is a final-delivery action, not the default result of editing.

## Workflow

1. Verify the target project and confirm the timeline is in the expected state.
2. Ask for the missing delivery choice only when needed: video, audio, subtitles, or editable archive.
3. Use the ChatCut export operation with the requested format and quality.
4. Report the returned job status or download link. Do not claim an export finished while it is still processing.
5. If export fails, preserve the editable project and explain the next available retry or manual UI path.
