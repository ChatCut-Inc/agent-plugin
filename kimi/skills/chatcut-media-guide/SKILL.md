# ChatCut Media Guide

Explain the upload boundary before importing: media sent through ChatCut is uploaded to ChatCut cloud storage.

## Import workflow

1. Confirm the user has agreed to upload the selected file.
2. Use the ChatCut import tool for an attached or supported local file; do not invent asset IDs or URLs.
3. If the host cannot pass the local file to the connector, open the project editor and ask the user to upload the file in the visible ChatCut page.
4. Wait for the import result and use the returned project-local asset ID for subsequent edits.
5. Verify that the asset appears in the project before placing it on the timeline.

Never upload files the user did not identify or approve. When browser file upload is unavailable, state the limitation and give the user the shortest manual upload step.
