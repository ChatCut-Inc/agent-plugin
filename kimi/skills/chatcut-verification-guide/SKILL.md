# ChatCut Verification Guide

Verify through ChatCut project state first and the in-app browser second.

## Checks

- Project identity: confirm the name and ID are the user's target project.
- Assets: confirm imported or generated assets exist and are referenced by the timeline.
- Timeline: confirm item order, start/end ranges, tracks, and duration.
- Captions: confirm text, timing, and language when captions were changed.
- Visual result: render a representative frame or open the live editor for user-visible review.
- Export: confirm the export job reached a completed state before sharing it.

If a check fails, report the exact affected part and avoid making unrelated corrective edits.
